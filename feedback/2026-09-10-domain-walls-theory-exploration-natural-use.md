## 讨论中提出的问题：判断与假设，不是已测量的因果结论

1. **思考切换与重复维护**：agent 判断，多层重述及维护引用、替代关系可能打断
   连续推导；本次没有量化打断次数，也不能把课题推进慢全部归因于 AITP。
2. **认识变化不等于旧结果失效**：一个计算可以仍然成立，但其假设、适用范围或
   对主问题的意义改变。`supersedes` 是记录关系，不自动表达这种科学关系；
   正文可以表达，但维护成本尚未测量。本例不要求新增语义推理 runtime。
3. **可追溯性不等于科学正确性**：保存、引用版本和校验不能判断推导是否正确，
   更不能判断该计算是否必要。倾向选择容易验证的小步骤，是待警惕的 agent
   行为风险；本次没有证明 AITP 导致了这种倾向。
4. **路线惯性**：机械执行旧 `next_action` 可能替代重新检查物理必要性；这是
   风险判断，不是对 CLI 错误调度的报告。研究方向与 host Goal 仍不归 ledger 决定。
5. **是否不用更好**：agent 的回答是“有可能，但未验证”。有详细推导、文献与
   简短交接的 plain-files 工作流，与没有任何持久记录不是同一对照条件。
   停用 AITP 不会自动解决错误的物理判断；此前过重的用法也由 agent 负责。
